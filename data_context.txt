DATABASE CONTEXT

The database contains sales transaction data from 2023 to 2025.

It consists of three tables:

1. sales
2. products
3. customers


==================================================
SALES TABLE
==================================================

Description:
Contains individual sales transactions.

Rows: 4,456

Columns:

- OrderID
  Type: string / UUID
  Description: Unique identifier for each order.
  Nullable: Yes

- CustomerID
  Type: string / UUID
  Description: Identifier of the customer who placed the order.
  Nullable: Yes
  Missing values: 24

- ProductID
  Type: integer
  Description: Identifier of the product sold.
  Nullable: No

- OrderDate
  Type: date
  Description: Date when the order was placed.
  Nullable: No

- Quantity
  Type: integer
  Description: Number of units sold.
  Nullable: No

- Revenue
  Type: float
  Description: Revenue generated by the order.
  Nullable: Yes
  Missing values: 41

- COGS
  Type: float
  Description: Cost of goods sold for the order.
  Nullable: No


==================================================
PRODUCTS TABLE
==================================================

Description:
Contains product information.

Rows: 50

Columns:

- ProductID
  Type: integer
  Description: Unique identifier of the product.

- ProductName
  Type: string
  Description: Name of the product.

- ProductCategory
  Type: string
  Description: Category of the product.

- Price
  Type: float
  Description: Listed selling price.

- Base_Cost
  Type: float
  Description: Base cost of the product.


==================================================
CUSTOMERS TABLE
==================================================

Description:
Contains customer information and geographic attributes.

Rows: 200

Columns:

- CustomerID
  Type: string / UUID
  Description: Unique identifier of the customer.

- Region
  Type: string
  Description: Geographic region of the customer.
  Example values: East, West.

- CustomerJoinDate
  Type: date
  Description: Date when the customer joined.


==================================================
RELATIONSHIPS
==================================================

sales.CustomerID = customers.CustomerID

sales.ProductID = products.ProductID


==================================================
ANALYTICAL RULES
==================================================

For regional analysis:

Join sales with customers using:

sales.CustomerID = customers.CustomerID

Use:

customers.Region


For product analysis:

Join sales with products using:

sales.ProductID = products.ProductID

Use:

products.ProductName
or
products.ProductID


For analysis involving both region and product:

Join sales with customers:

sales.CustomerID = customers.CustomerID

And join sales with products:

sales.ProductID = products.ProductID


For date-based analysis:

Use:

sales.OrderDate


For revenue analysis:

Use:

sales.Revenue


For cost analysis:

Use:

sales.COGS


For profit analysis:

Profit = Revenue - COGS


==================================================
COMMON METRICS
==================================================

Total Revenue:

SUM(Revenue)


Total COGS:

SUM(COGS)


Total Profit:

SUM(Revenue - COGS)


Total Quantity Sold:

SUM(Quantity)


Average Revenue:

AVG(Revenue)


==================================================
DATA QUALITY
==================================================

sales.CustomerID contains 24 NULL values.

sales.Revenue contains 41 NULL values.

Transactions with a NULL CustomerID cannot be associated
with a customer region.

NULL Revenue values should be handled appropriately when
calculating revenue-based metrics.

The sales dataset covers 2023 through 2025.
